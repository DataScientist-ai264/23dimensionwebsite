# Portfolio Images

Place your portfolio images in this directory with the following names:

## Required Images (1200x800px recommended):

- `market-analysis.jpg` - AI/ML dashboard screenshot or mockup
- `blockchain-supply.jpg` - Blockchain network visualization
- `fintech-app.jpg` - Mobile app screenshots
- `market-entry.jpg` - Strategic framework diagram
- `quantum-research.jpg` - Scientific/research visualization
- `esg-advisory.jpg` - ESG dashboard or infographics

## Image Guidelines:

- **Size:** 1200x800px (3:2 aspect ratio)
- **Format:** JPG or PNG
- **Quality:** High resolution, professional appearance
- **Style:** Consistent with your brand (cyan/gold accents recommended)
- **Content:** Screenshots, mockups, diagrams, or professional visualizations

## Placeholder Images:

If you don't have images ready, you can use placeholder services like:

- Unsplash: https://unsplash.com (search for tech, business, analytics)
- Pexels: https://pexels.com
- Custom mockups: Use Figma or Sketch to create professional-looking interfaces
